8 Open-Source LLMs That Now Beat GPT-4 Class — and What Hardware Each Needs

July 15, 2026 · Open Source / LLMs / Self-Hosting

Open-source LLMs don't just "compete" with proprietary models anymore. On coding, math, and long-context tasks, they're winning. The gap between a $200/month API bill and a self-hosted open model has never been smaller.

I benchmarked all eight open-weight models that matter in July 2026 — from Qwen 3's 235B MoE powerhouse down to Phi-4's 14B edge-ready reasoning engine. Three of them now match or exceed GPT-4-class performance on standard benchmarks. Here's what shipped, what the numbers say, and exactly what hardware you need to run each one.

The headline: Qwen 3 235B-A22B leads overall reasoning and coding. DeepSeek R1 dominates deep math. Llama 4 Scout owns long context with a 10M token window. And for single-GPU setups, Gemma 3 27B and Phi-4 14B deliver frontier-tier performance at 8–16 GB VRAM.

The July 2026 Open-Source Leaderboard

Every model in this ranking was evaluated across five dimensions: benchmark performance (MMLU, HumanEval, AIME, SWE-bench), hardware accessibility, license freedom, ecosystem maturity, and real-world adoption. Models that require a GPU cluster nobody can afford get penalized. Restrictive licenses lose points.

#1 — Qwen 3 235B-A22B: Best Overall

  • Architecture: Mixture-of-Experts, 235B total, only 22B active per token
  • License: Apache 2.0 (full commercial use)
  • VRAM (Q4): ~132 GB — needs 5× RTX 3090s, 3× A40s, or a dual-H100 rig
  • Standout: Dual-mode thinking (chain-of-thought toggle), 256K context, 100+ languages

Alibaba's Qwen 3 is the model to beat. Its MoE architecture slashes compute by roughly 90% compared to a dense model of similar quality — 235B parameters, but only 22B activate per token. The dual-mode thinking system lets you toggle between explicit chain-of-thought for hard problems and a fast non-thinking mode for quick chat.

The benchmark numbers put it in the same tier as DeepSeek R1, OpenAI's o1, and Gemini 2.5 Pro:

  • AIME 2024: 85.7% (competition-level math)
  • AIME 2025: 81.5% (harder problems)
  • LiveCodeBench v5: 70.7% (real coding tasks)
  • CodeForces: 2,056 rating (competitive programming)
  • BFCL v3: 70.8% (function calling)

The Qwen 3 family also ships smaller variants (32B, 14B, 8B, 4B) that run on consumer hardware. If you're planning to fine-tune for a specific domain, the Apache 2.0 license gives you full freedom.

#2 — DeepSeek R1: Best for Deep Reasoning

  • Architecture: 671B MoE, 37B active
  • License: MIT
  • VRAM (Q4): ~136 GB
  • Standout: Self-correcting chain-of-thought, distilled variants from 1.5B to 70B

DeepSeek R1 proved open-source models could match OpenAI's o1 on reasoning. The R1-0528 update pushed AIME 2025 accuracy from 70% to 87.5%. The secret: DeepSeek first trained R1-Zero using pure reinforcement learning with no supervised fine-tuning warmup. The model spontaneously developed chain-of-thought reasoning, self-verification, and backtracking. It literally taught itself to check its own work.

Key benchmarks:

  • AIME 2025: 87.5% (math olympiad level)
  • GPQA Diamond: 71.5% (graduate-level science)
  • SWE-bench: 49.2% (real software engineering)
  • HumanEval: 92.4% (code generation)

Practical tip: The 32B distilled variant runs on a single RTX 4090 and still outperforms many larger models on reasoning. If you need chain-of-thought on a budget, start there.

#3 — Llama 4 Scout: Best for Long Context

  • Architecture: 109B MoE, 17B active, 16 experts with 2 active
  • License: Llama Community License
  • VRAM (Q4): ~55 GB — fits on a single H100 (80 GB)
  • Standout: 10 million token context window

That's not a typo. 10 million tokens. You can feed Llama 4 Scout an entire codebase, a shelf of research papers, or 20 hours of video transcription in a single prompt. It uses a novel inter-document attention masking approach that maintains document boundaries within the massive context window.

The results are remarkable:

  • Needle-in-a-Haystack (10M): 100% — perfect retrieval
  • MMLU: 79.6%
  • HumanEval: 81.2%
  • DocVQA: 85.1% (document understanding)

Most models lose information well before 128K tokens. Scout's perfect retrieval at 10M is genuinely new. The catch: actually using the full context window requires enormous KV cache memory. In practice, most self-hosted deployments cap at 128K–256K tokens.

MoE vs Dense: The Critical Hardware Trap

Here's the single most misunderstood concept in self-hosting LLMs in 2026: MoE models save compute, not memory.

A Mixture-of-Experts model like Qwen 3 235B has 235 billion total parameters, but only 22 billion activate per token. The router selects which "experts" to use for each token, making inference fast — roughly 10× faster than a dense 235B model. But here's the trap: all 235B parameters must be loaded into VRAM. The router needs access to every expert because it doesn't know which ones it'll need until it sees the input.

  • MoE saves: compute (FLOPs per token), inference latency, electricity costs
  • MoE does NOT save: VRAM, model download size, storage
  • Rule of thumb: A 235B MoE with 22B active still needs 235B worth of VRAM

This is why a "22B active" model still requires 132 GB of VRAM. The parameter count that matters for hardware planning is the total count, not the active count. Don't let marketing fool you — always check total params when sizing your GPU.

The Single-GPU Champions

Not everyone has a multi-GPU rig. Two models on this list run on hardware you can buy at a consumer electronics store.

Gemma 3 27B: Multimodal on One Card

  • VRAM (Q4): ~16 GB — runs on a single RTX 4090 (24 GB)
  • Multimodal: text + image input natively
  • Languages: 140+ supported
  • Context: 130K tokens

Don't let the modest 27B parameter count fool you. On multimodal tasks, Gemma 3 27B punches well above its weight:

  • DocVQA: 85.6% — document understanding competitive with models 3–5× larger
  • ChartQA: 76.3% — visual reasoning from charts and graphs
  • MGSM: 74.3% — multilingual math

Even an M2 MacBook Pro with 32 GB unified memory can run it. If you need image understanding without renting cloud GPUs, Gemma 3 is the obvious choice.

Phi-4 Reasoning: Edge-Ready Intelligence

  • VRAM (Q4): ~8 GB — laptop GPU territory
  • Params: 14B dense
  • License: MIT (no commercial restrictions)

Microsoft's Phi-4 proves parameter count isn't everything. At 14B, it outperforms DeepSeek R1's 70B distill on several reasoning benchmarks. The secret is training data quality — Microsoft prioritized curated, high-quality data over raw scale, and it works:

  • MATH: 82.6% — beats Gemini Pro and GPT-4o-mini on math reasoning
  • HumanEval: 82.6% — solid code generation
  • MGSM: 80%+ — multilingual math

The Phi-4-reasoning-vision-15B variant adds multimodal capabilities, scoring 17% higher than Gemma 3 12B on math-visual reasoning. For edge deployment, mobile, or on-device AI, Phi-4 is one of the few models that runs with reasonable latency.

The Coding Champion: GLM-4.7

  • Architecture: 355B MoE, 32B active
  • License: MIT
  • VRAM (Q4): ~130 GB
  • Standout: Persistent thinking blocks across entire conversations

Z.ai's GLM-4.7 is purpose-built for agentic coding. Unlike most models that restart reasoning each turn, GLM-4.7 retains its thinking blocks across the entire conversation. That persistent reasoning context matters when orchestrating complex multi-step coding tasks.

The benchmarks are competitive with Claude Sonnet 4.5:

  • SWE-bench: 73.8% — real-world software engineering, not synthetic benchmarks
  • HumanEval: 94.2% — the highest of any model on this list
  • Context: 200K tokens, 131K max output

DeepSeek V3: The Practical Workhorse

While R1 gets headlines for reasoning, V3 is the more practical daily driver — fast, capable across the board, and remarkably efficient. It shares the 671B MoE / 37B active architecture but trades deep reasoning chains for faster response times.

The V3-0324 update incorporated RL techniques from R1's training, boosting reasoning without the latency hit of explicit chain-of-thought. Training efficiency is legendary: only 2.788 million H800 GPU hours for the full pre-training run — a fraction of what comparable models require.

  • MMLU: 87.1%
  • HumanEval: 82.6%
  • MATH: 90.2%
  • Context: 128K

Mistral Large 3: Enterprise & Multilingual

Mistral's 675B MoE (41B active) brought the French lab back to the frontier under a full Apache 2.0 license — a major shift from the restrictive research license of Large 2. Trained from scratch on 3,000 NVIDIA H200 GPUs.

  • Multilingual MMLU: 85.5% — cross-language knowledge
  • LMSYS Arena: Ranked #6 overall (including proprietary models)
  • Anti-hallucination: Trained to say "I don't know" rather than fabricate

That last point makes Mistral Large 3 a strong fit for RAG pipelines and enterprise applications where factual accuracy matters more than creative output.

Getting Started: The Practical Path

All eight models are available on Hugging Face and run through standard inference engines. Here's the fastest path from zero to running:

Option 1: Ollama (Easiest, Single Command)

# Pull and run Gemma 3 27B on a single GPU
ollama run gemma3:27b

# Or Phi-4 on a laptop
ollama run phi4

# DeepSeek R1 32B distill on RTX 4090
ollama run deepseek-r1:32b

Option 2: llama.cpp (Maximum Control)

# Build and run with specific quantization
./llama-cli -m qwen3-235b-q4_k_m.gguf \
  -c 32768 \
  -ngl 99 \
  --color \
  -i

Option 3: vLLM (Production Serving)

# Serve with OpenAI-compatible API
python -m vllm.entrypoints.openai.api_server \
  --model Qwen/Qwen3-235B-A22B \
  --tensor-parallel-size 4 \
  --quantization awq

The Honest Reality Check

Let's separate signal from noise:

  • The gap to proprietary models is real but closing. On coding and math benchmarks, the best open-source models match or beat GPT-4.5. The gap is narrowest in structured tasks and widest in creative writing and nuanced instruction following.
  • Hardware is the real bottleneck. A 235B MoE model, even with only 22B active, still requires server-grade hardware to deploy. The VRAM cost is the total parameter count, not the active count.
  • Licenses matter for production. Apache 2.0 and MIT give you full commercial freedom. Llama's custom license restricts apps with 700M+ users. Always read the license before deploying.
  • Distilled variants are underrated. DeepSeek R1's 32B distill, Qwen 3's 14B variant, and Phi-4 at 14B all deliver remarkable performance on consumer hardware. Don't overlook them.
  • Context windows have a practical ceiling. Llama 4 Scout's 10M context is architecturally real, but KV cache memory means most self-hosted deployments cap at 128K–256K tokens.

The Bottom Line

We've reached the point where open-source LLMs are no longer a compromise. Qwen 3, DeepSeek R1, and GLM-4.7 deliver GPT-4-class performance on reasoning, coding, and math — and you can download them, fine-tune them, and deploy them wherever you want.

The question isn't whether open-source models are good enough. They are. The question is whether your hardware can run them. Start with Gemma 3 27B or Phi-4 on whatever GPU you have. Scale up to Qwen 3 or DeepSeek when your use case demands it. The models are ready. The hardware is the conversation worth having.
